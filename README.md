4-Bit Processor using Verilog HDL

This project implements a 4-bit processor in Verilog HDL to demonstrate the fundamentals of processor architecture and digital system design. The processor is capable of executing a small instruction set and integrates essential components required for instruction execution.

Features
4-bit data path
Arithmetic Logic Unit (ALU)
Register File
Program Counter (PC)
Instruction Decoder
Control Unit
Memory Interface
Clock and Reset Support
Simulation using ModelSim/Xilinx Vivado
Supported Operations
Addition
Subtraction
AND
OR
XOR
NOT
Data Transfer (MOV/LOAD/STORE)
Conditional and Unconditional Branching
Technologies Used
Verilog HDL
Digital Logic Design
FPGA Design
ModelSim / Vivado (Simulation)
Applications
Educational processor design
Computer architecture learning
Digital electronics projects
FPGA implementation practice
Learning Outcomes
Processor architecture fundamentals
Instruction execution cycle
Control unit design
ALU implementation
Register transfer operations
Verilog HDL coding and simulation
