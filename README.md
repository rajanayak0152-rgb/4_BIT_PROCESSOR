# 4-Bit Processor using Verilog HDL

A simple 4-bit processor designed in Verilog HDL to demonstrate the fundamentals of processor architecture and digital system design.

## Features
- 4-bit ALU
- Register File
- Program Counter (PC)
- Instruction Decoder
- Control Unit
- Arithmetic and Logic Operations
- Data Transfer Instructions

## Technologies Used
- Verilog HDL
- ModelSim / Vivado

## Applications
- Processor architecture learning
- FPGA implementation
- Digital design projects
